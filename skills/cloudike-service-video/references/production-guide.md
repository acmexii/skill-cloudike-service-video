# 참고 영상과 제작 기준

참고: https://www.youtube.com/watch?v=_tDhNoVpBv8
제목: 튜토리얼 | AI 영상 분석부터 숏폼 생성까지, 업로드 한 번이면 끝 | 브이픽(Vpick)
2026-10-24 KST 확인. 플레이어 길이 5:04. 직접 확인한 정지 장면은 0:05 업로드 UI, 0:29 요약 카드 강조, t=90s로 탐색한 중반 기능 설명 화면이다. 중반 화면의 정확한 재생 시각은 재확인한다.
관찰: 실제 앱 UI가 화면 대부분을 차지하고, 주변 암전과 밝은 대상 영역이 대비된다. 보라색 점·연결선·둥근 설명 상자·흰 글자로 위치와 의미를 연결한다. 전체 UI 맥락이 남아 있다.
미확인: 전체 컷 구성, 정확한 확대 배율·시간·폰트·오디오·내레이션 운율. 아래 수치는 원본 측정값이 아닌 제작 시작값이다. 제작 전에 원본을 재생·청취해 분석을 보완한다.

| 항목 | 시작값과 원칙 |
|---|---|
| 화면 | 16:9, 1080p, 30fps; 가능한 고해상도 원본 캡처 |
| 브랜드 | 현재 Cloudike 사이트/제공 자산에서 색상·로고 확인; 참고 영상 보라색을 Cloudike 브랜드 색이라 주장하지 않음 |
| 확대 | 1.15~1.7배, 0.45~0.8초 ease-in-out; 2배 초과보다 재캡처 우선 |
| 강조 | 주변 35~55% 암전, 대상 1개는 밝게 유지; 대상도 어두워지는 전체 덮개 금지 |
| 설명 상자 | 점+연결선+둥근 상자, 핵심 1~2줄; 중요 UI 가림 금지 |
| 자막 | 1080p 기준 40~48px, 최대 2줄, 가장자리 5% 여백; 축소 화면에서 확인 |
| 전환 | 같은 작업은 컷, 의미 전환은 0.2~0.4초 디졸브를 시작점으로 조정 |
| 음성 | 차분한 존댓말; 기능 다음에 업무 효용; 실제 발화 길이로 장면 조정 |
| 오디오 | 최종 약 -16 LUFS, true peak ≤ -1 dBTP; 발화 때 BGM을 12~18dB 낮게 시작해 청취 조정 |

장면 동선은 전체 맥락 → 대상 이동/확대 → 조작/설명 → 강조 → 결과 체류 → 다음 화면. 강조는 발화 직전 0.15~0.3초, 결과는 발화 후 0.5~1초 체류를 시작점으로 삼는다. 수치를 기계적으로 강제하지 않는다. 로딩 단축을 처리 성능 주장으로 사용하지 않는다. 원본 영상의 대본·음원·로고를 복제하지 않는다.

페이지의 “iOS Finder”는 PC 설명과 맞지 않는 표기이므로 그대로 낭독하지 않는다. 앱별 Windows/macOS 지원 명시를 따른다. 보안 인증·고객 수·가격·무료체험 기간은 기본 대본에서 제외하고 필요 시 적용 상품·범위·최신 조건을 확인한다. AI/GPU/백업 부가 서비스는 기본 스토리지 기능과 혼합하지 않는다.
추천 스토리: 흩어진 업무 문서 → 문서함 → 내부 권한/외부 공유 → 공동 편집 → 이력과 복원 → PC 연결 → 홈페이지 방문. 가상 업무 예시는 데모임을 구분한다.
