# 자연스러운 타이핑과 마우스 연출

목표는 사람이 업무를 처리하는 흐름을 시청자가 따라갈 수 있게 보여주는 것이다. 실제 서비스의 화면 상태·클릭 결과·입력 내용이 우선이며, 연출은 가독성과 이해를 돕는다. 아래 시간은 제작 시작값으로 길이와 작업 난이도에 맞게 조정한다.

## 조작 순서
전체 맥락을 0.5~1초 보여준 뒤, 포인터 이동 → 짧은 호버 → 클릭 → 실제 화면 반응 → 입력/확인 → 결과 체류 순서로 구성한다. 설명하는 기능에 맞춰 내레이션·확대·강조를 배치한다. 메뉴나 결과가 나타났는지 확인한 다음 조작하며 고정 대기 시간만으로 완료를 판단하지 않는다.

## 타이핑
- 입력 필드로 포인터를 이동해 클릭하고, 포커스와 캐럿을 확인한 뒤 입력한다. 폴더명·검색어 등 짧은 데모 문자열은 한 번에 채우거나 붙여 넣지 않고 입력 진행이 보이도록 한다.
- 영문·숫자는 글자당 약 70~140ms를 시작값으로 사용한다. 단어 사이 120~250ms, 구절 사이 250~450ms 정도의 짧은 호흡을 줄 수 있다. 극단적인 무작위 지연이나 일부러 낸 오타를 추가하지 않는다.
- 한국어는 도구가 지원하는 실제 IME 조합 입력을 우선한다. 지원하지 않으면 완성형 음절을 순서대로 넣어 자연스럽게 보이게 하고, 실제 자모 조합을 재현했다고 주장하지 않는다. 결합 문자나 이모지를 잘못 분리하지 않는다.
- 입력 완료 후 0.4~0.8초 동안 결과를 읽을 시간을 준 다음 검색·저장·확인을 수행한다. 자동완성·검색 갱신이 입력 중 발생하면 실제 응답을 기다린다.
- 긴 본문이나 실제 업무상 붙여 넣기가 자연스러운 작업은 붙여 넣기를 사용할 수 있다. 모든 글자를 느리게 입력해 영상 길이를 낭비하지 않는다.

## 마우스·클릭·스크롤
- 사용 환경에서 지원하는 UI 조작/녹화 도구를 사용한다. 포인터 이동을 지원하면 출발점에서 목표까지 약 0.35~0.8초로 이동하고 시작·종료를 부드럽게 감속한다. 긴 이동은 최대 약 1.2초로 조정한다. 약한 곡선은 사용할 수 있지만 과한 흔들림·반복 왕복은 피한다.
- 대상 위에 약 0.15~0.3초 머문 뒤 클릭한다. 버튼 중앙 또는 실제 클릭 가능한 영역을 목표로 삼으며, 이동 중 레이아웃이 바뀌면 새 화면에서 대상을 다시 확인한다.
- 최종 1080p에서 포인터가 식별되도록 약 28~36px부터 조정한다. 클릭은 브랜드색 링 하나가 약 0.2~0.35초 확산·소멸하도록 표시할 수 있다. 입력 중에는 커서를 중요한 텍스트 위에 두지 않는다.
- 실제 녹화가 포인터를 포함하는지 먼저 짧게 확인한다. 녹화에 포인터가 빠지는 경우 실제 입력 이벤트와 좌표에 맞춘 오버레이를 사용하고, 원본 포인터와 이중으로 보이지 않게 한다. 정적인 공식 이미지 위 포인터는 위치 설명용으로만 사용한다.
- 스크롤은 약 0.5~0.9초 동안 한 번에 읽을 수 있는 구간씩 이동하고, 멈춘 뒤 0.4~0.8초 체류한다. 목표를 찾기 위한 불필요한 급격한 상하 왕복은 편집에서 정리한다.
- 확대·패닝·크롭에 화면과 커서·클릭 표시를 같은 좌표 변환으로 적용한다. 전환 중에는 커서가 새 화면의 엉뚱한 버튼을 가리키지 않게 실제 다음 시작 위치로 이어주거나 짧게 페이드한다.

## 도구 지원 범위와 진실성
도구에 없는 이동·녹화 API를 가정하거나 임의 조작 방식을 사용하지 않는다. 실제 조작 이벤트를 기록할 수 있으면 시간과 원본 좌표를 보관한다. 실제 이벤트 없이 공식 자료에 합성한 커서로 기능이 작동한 것처럼 결과 화면을 만들지 않는다. 앱 접근이 없는 장면은 공식 자료를 활용한 설명 장면으로 표시하고, 가능한 실제 홈페이지 탐색 장면에서 자연스러운 조작을 보여준다.

## 장면 기록과 검수
storyboard.json의 interactions에 다음 정보를 기록한다.

```json
{
  "time": 1.2,
  "action": "move_then_click",
  "target": "검색 입력란",
  "duration": 0.55,
  "coordinate_space": "source_normalized",
  "render_mode": "recorded_input",
  "expected_result": "검색 입력란에 포커스와 캐럿 표시"
}
```

원본 좌표와 이동 경로는 실제 캡처에서 확인한 값을 기록한다. 텍스트 입력 장면에는 데모 문자열·입력 방식·소요 시간을 추가한다. 실제 녹화, 실제 이벤트 기반 커서 합성, 공식 자료의 설명용 커서 합성을 구분한다.

대표 조작 장면을 정상 속도로 재생해 이동 → 클릭 → 입력 → 결과의 순서와 리듬을 확인한다. 한글 입력 과정, 커서 식별성, 확대 후 클릭 정렬, 자막 가림, 결과 체류를 점검하고 빠르게 넘겨도 이해되는지 확인한다. 수행한 검수 범위만 qa.md에 기록한다.
