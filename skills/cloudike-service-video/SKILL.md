# Cloudike 기업 영상 제작

## 입력과 목표
실제 화면으로 기능을 입증하고 업무 가치를 설명한다. 기본 사이트는 https://cloudike.kr/, 연출 참고는 https://www.youtube.com/watch?v=_tDhNoVpBv8 이다. 기본 제안은 한국어, 90~120초, 16:9, 1920×1080, 30fps이며 사용자 지정을 우선한다.
착수 시 [연출과 기능 근거](references/production-guide.md)를 읽고, 음성 생성 시 [ElevenLabs](references/elevenlabs.md)를 읽는다.
화면 조작 장면은 [자연스러운 타이핑과 마우스 연출](references/interaction-motion.md)을 적용한다. 입력 과정과 포인터 이동이 실제로 보이도록 구성하고 조작 결과를 확인한다.

## 제작 절차
1. 참고 영상을 도입·기능 설명·마무리까지 실제 재생·청취하고 관찰 타임코드와 연출 특징을 기록한다. 기존 기록은 부분 정지 장면 분석이므로 전체 분석 완료로 간주하지 않는다. 미확인 항목은 추정값이라 명시한다.
2. 홈페이지와 공식 기능 상세 페이지를 다시 열어 최신 기능·지원 환경·조건을 검증한다. evidence.json에 claim_id, 설명, URL, 확인일, 화면 출처, 검증 상태를 기록한다. 사이트의 숨은 템플릿 문구와 오탈자를 제품 사양으로 채택하지 않는다.
3. 공개 홈페이지 화면, 공식 제품 이미지, 로그인 앱의 실제 조작 화면을 구분한다. 공식 이미지를 조작 시연으로 위장하지 않는다. 앱 화면이 없으면 공개 화면으로 소개 영상을 진행하고 부족한 시연만 명시한다. 생성형 영상으로 UI·기능을 만들어 대체하지 않는다. 데모 파일만 사용하며 임의 가입·기업 문서 수정·외부 공유를 하지 않는다.
4. 문제 → 가치 → 문서 관리/공유 → 공동 편집 → 이력/권한 → PC 연동 → 다음 행동을 목적에 맞게 구성한다. 장면당 메시지 하나를 실제 화면으로 입증한다. 부가 서비스는 요청 시 별도로 다룬다.
5. storyboard.json에 장면 id, claim_ids, source_asset, source_type, narration, caption, duration, crop, focus_rect, callout, transition, audio_file, audio_offset을 기록한다. 좌표는 원본 크기와 함께 또는 0~1 정규화로 기록한다. 환경에서 지원하는 캡처·녹화 도구를 사용한다.
   조작 장면에는 interactions 배열을 추가해 시각, 이동 경로/대상, 클릭·입력·스크롤, 예상 결과, 실제 녹화인지 설명용 오버레이인지 기록한다. 실제 앱 조작 녹화가 가능하면 이를 우선하고, 공식 이미지에 커서를 합성한 경우 실제 기능 실행으로 설명하지 않는다.
6. 첫 20~30초 대표 구간에 실제 화면·확대·강조·자막·음성을 적용해 검수한다. 승인 절차를 요청받지 않았다면 전체 제작을 이어간다.
7. 지정 Voice ID로 장면별 내레이션을 생성하고 실제 길이와 문자 타이밍에 화면·자막을 맞춘다. 낭독 대본, 핵심 강조 문구, 실제 발화와 일치하는 SRT를 구분한다. 음성은 scripts/elevenlabs_tts.py로 생성할 수 있다.
8. 지원 편집기 또는 코드 기반 렌더러로 확대·패닝·마스크·콜아웃·전환을 합성한다. 정지 이미지 슬라이드를 완성된 실제 조작 시연이라고 보고하지 않는다. 렌더링 도구가 없으면 정확한 장애와 완료 범위를 기록한다.
9. 완성 영상을 처음부터 끝까지 재생·청취하고 오류 구간을 수정한다. 실제 수행한 검수만 qa.md에 기록한다. 사용자가 영상 제작을 요청했다면 대본이나 기획안만 만들고 완료하지 않는다.

## 납품과 완료 기준
- 기능 설명마다 근거가 있고 화면·강조·음성이 같은 대상을 가리킨다. 미리보기와 편집, PC 클라이언트와 클다스트림, 일반 상품과 공공기관용 인증을 구분한다.
- 1080p 최종 화면에서 UI와 자막이 읽히고 잘림·겹침·오탈자가 없다. 확대가 메뉴·결과를 자르지 않는다. 자막은 기본 2줄 이내, 발화 구절과 약 0.2초 이내로 맞춘다.
- 조작 장면에서 마우스가 대상까지 부드럽게 이동하고 클릭 위치·입력 과정·처리 결과가 보인다. 한글 조합 깨짐, 포커스 오류, 커서 순간이동·중복, 확대 후 클릭 위치 이탈, 결과보다 빠른 다음 조작이 없다. 지원하지 않는 녹화·입력 방식은 사용한 대안과 한계를 기록한다.
- 음절 잘림·과한 무음·억양 불연속·음량 급변이 없고 제품명 발음을 직접 듣고 확인한다. 전체 시청·청취 여부, 실제 출력 규격, 음량 측정, 미해결 제한을 기록한다.
- final.mp4, captions.srt, narration.txt, storyboard.json, evidence.json, qa.md와 재렌더링 가능한 편집 프로젝트/코드·원본 자산을 납품한다. 비밀 저장소는 제외한다.

## 비밀과 실행 범위
기본 Voice ID는 `1PdAOcPlPTz12RwMyFVp`이며 임의 대체하지 않는다. 키는 ELEVENLABS_API_KEY 또는 별도 Windows DPAPI 저장소에서 읽는다. 키를 스킬·소스·로그·결과물에 적거나 출력하지 않는다. 오류 시 무한 재시도하지 않는다. 스킬 생성은 유료 합성·게시 요청을 포함하지 않는다. 영상 제작 요청 시 그 범위에서 진행하며 업로드·메일 발송은 별도 요청이 있을 때 한다.
